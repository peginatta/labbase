# LabBase

Lab records for an antileishmanial drug-discovery lab, kept as **plain Markdown notes in an
Obsidian vault** (strains, cell lines, compounds, media, freezer boxes, stocks, notebook), plus a
small optional tool, `labbase`, that checks and maintains the vault.

- `vault-demo/` — an example vault: open it in Obsidian (*Open folder as vault*). Its `README.md`
  explains the conventions.
- `labbase/` — the command-line tool (`uv run labbase --help`).
- `docs/maintainers.md` — how to look after the vault.
- `PLAN.md` — the long-term plan; `PROGRESS.md` — what's done.
